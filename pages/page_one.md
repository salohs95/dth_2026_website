# Advantages of open source software

When I think of the open-source approach, I think of it as way of seeing the world, a way of changing the world, and a way of manipulating the world.

## What does open source mean?

Open Source refers to software whose source code is accessible, allowing developers to examine, modify and distribute it under the licence conditions (Berry, 2008).

Closed source is often copyright protected, have patents, have software licenses, restricted on copying and modifying the code and most important keeping the source code a secret (Berry, 2008).
